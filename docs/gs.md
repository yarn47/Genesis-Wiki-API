# G.S

배포 시 011_bifrost_faction.sql을 캐릭터 동기화 전에 적용해야 한다. 이 작업에서는 DB에 실행하지 않았다.

- 사용자 제공 스크린샷 7574~7610 기준. 출시일 2024-01-09, 출현작 창세기전2.
- 영웅 / 비프로스트 / 욕망의 그림자 / 출생 불명 / 180cm / 장민혁.
- 필살기·전용무기·발현 없음. 장비 포함 화면 능력치는 기본 능력치로 등록하지 않음.
- 잿빛 새벽 각성 2~6: 디버프당 치명타 확률 5/6/7/8/9%, 받는 피해 감소 및 공격력 기준 회복 50/55/60/65/70%.
- 느려짐: 각성 2~4는 1단계, 5~6은 2단계. 모두 2턴 부여. 공유 느려짐 1의 기존 기본 지속시간은 보존하며 G.S 스킬 본문에 2턴을 명시.
- 클래스: 레인저→스카우트→하이마스터, 파이터→소드맨→소드마스터. 파이터 계열과 약점 파악은 기존 데이터 재사용.
- 7590~7598 레인저, 7600~7604 스카우트, 7606~7610 하이마스터 자료.
- 심안은 패시브 레벨별 기본 감소 15/20%, 심안 없는 적에게 피격 시 감소 15/20%를 별개 원문으로 유지. 합산 공식을 추정하지 않음.
- 간파 1/2는 10/15%, 심안 디버프는 1턴·25% 감소·치명타 관련 20%.

검증: 데이터 단위 테스트, SQL 생성(실제 DB 적용 아님), 이미지 경로 및 프론트 빌드, 로컬 읽기 전용 미리보기.

결과: 데이터 테스트 62개 통과. 서버 전체 테스트 17개 중 DB 연결이 필요한 contextLoads 1개는 Hibernate Dialect 초기화 실패. 변경 관련 CharacterRequestTest와 ClassTreeParentResolverTest는 별도 실행하여 통과.
