# 모르가이나 쉘렌

- 사용자 제공 게임 스크린샷 7346, 7350~7448 기준. 출시일 2024-01-09, 출현작 없음은 사용자 확인.
- 고유 패시브 각성 3~6, 발현 2/4/6. 달의 의지·달의 이면은 해제 불가 영구 버프. 부활 시 서로 교체하며 게임당 1회 발동.
- 필살기 자료/표시가 없는 캐릭터이므로 필살기를 생성하지 않음. 장비가 반영된 화면 능력치는 기본 캐릭터 능력치로 입력하지 않음.
- 시스터, 메이지, 위자드, 다크위자드와 치밀한 준비는 기존 데이터를 재사용. 프리스트·하이프리스트 추가. 썬 라이트는 팔라딘의 기존 동일 스킬을 공유.
- 마력의 공명석 및 그림자의 빛 4단계와 관련 상태 효과 추가.
- 크레센트 로드 1~6성: 체력 130/131/132/134/135/136, 주문력 342/345/349/353/356/360.
- 전용 월광은 3턴, 만료/해제 시 생성되는 보호막은 2턴. 일반 공세전환과 전용 치유 의지/맹공 의지를 구분.
