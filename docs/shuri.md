# 슈리 스탐가르드 자료 반영

- 사용자 제공 사진 6661~6773 기준. 출시일 2024-01-09, 출현작 창세기전2는 기존과 동일하다는 사용자 지시로 입력.
- 고유 패시브 각성 3~6, 발현 2/4/6; 필살기 기본/발현 1/3/5 입력.
- 파이크, 템플러, 랜서, 하이템플러, 법왕기사, 로얄랜서 공용 클래스 6종과 액티브 8종 추가. 로얄랜서는 다른 캐릭터에서 제공한 6757~6763 자료를 사용.
- 최상의 상태, 기절, 감전, 둔화, 출혈은 기존 데이터 재사용. 나선 문장의 출혈 지속은 사진의 3턴을 아티팩트 본문에 명시하며 기존 출혈의 기본 2턴을 전역 변경하지 않음.
- 무기 기본 능력치 1~5성은 6765~6773, 6성 최대 체력 133/공격력 365는 사용자 텍스트 확인.
- 캐릭터 화면 장착 능력치는 기본 능력치로 입력하지 않음.
- 광룡탄·징벌의 갑옷·생텀 스피어는 마법 아이콘 확인, 전격/광휘 속성 입력. 나머지 공격 스킬은 창 기본 관통.
- 로컬 JSON 미리보기는 Spring API/DB 검증을 대체하지 않음. 커밋/배포 미실행.

검증: gen_sql.py, unittest 47개, 프론트 빌드 및 브라우저 미리보기.
