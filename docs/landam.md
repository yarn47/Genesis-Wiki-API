# 랜담 켈빈스

사용자가 제공한 게임 스크린샷 7450~7526을 근거로 추가했다.

- 기본 프로필: 7450/7452. 장비가 반영된 화면 수치는 캐릭터 기본 스탯으로 입력하지 않음.
- 외눈의 용병: 각성 3~6 및 발현 2/4/6. 발현의 헤비 아머 클래스 **보유** 조건은 원문 유지.
- 교아참: 기본 200%는 사용자 정정값. 발현 1/3/5는 210/220/230%. 총 네 단계이며 나머지 조건은 동일.
- 클래스는 기존 파이크·가드·제너럴·어스퀘이커·마샬·로얄랜서 재사용. 공용 부모를 수정하지 않고 CharacterService의 부모 해석에서 트리에 없는 부모만 대체한다.
- 랜담 경로: 파이크 → 가드 → 어스퀘이커 / 파이크 → 제너럴 → 마샬·로얄랜서.
- 팔랑크스 전술서는 제공된 네 단계가 기존 번스타인 데이터와 일치. 섬광연격 비전서도 기존 데이터 재사용.
- 가시 군주의 반지 신규 추가 및 맹위·무력 4단계 등록.
- 게이볼그는 Lv50 스크린샷의 1~6성 수치. 업화 30/32/34/36/38/40%, 파이어 웨이브 20/22/24/26/28/30%.
- 무기 배경 설명은 자료가 없어 생략. 출시일·출현작도 확인 전 추정 입력하지 않음.

검증: Python 데이터 테스트, SQL 생성(실제 DB 실행 아님), Kotlin 클래스 연결 회귀 테스트, 프론트 빌드 및 읽기 전용 로컬 JSON 미리보기. 배포는 별도 작업.
