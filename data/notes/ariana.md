# 아리아나 위버 입력 기록

2026-09-29 사용자 제공 게임 스크린샷 49장 및 아티팩트 표 기준. 푸시/배포 및 운영 DB 반영 전 로컬 작업 상태.

## 확정 정보
- 출시일 2024-01-09, 출현작 창세기전2 (번스타인과 동일하다고 사용자 확인).
- 커티스 / 전설 / 활력의 나무. 커티스 enum 및 마이그레이션 007 추가.
- 필살기 이름 **화염인**: 사용자 일시 오타 `화염`을 다시 정정함. 공격 타입 **관통**은 사용자 확인, 속성 화염.
- 노발현 피해량은 사용자 지시에 따라 1발현 100%에서 단계 격차 10%p를 뺀 90%. 원본 스킬 탭과도 일치. 생성 확률 25%, 발현 1/3/5는 30/30/35%.
- 아티팩트 순서: 속성 과부하 → 최상의 상태 → 질풍의 깃. 앞의 두 아티팩트와 철수, 갑옷 파괴는 기존 데이터 재사용.
- 질풍의 깃 등급은 제공 자료에 없어 임의로 지정하지 않음.
- 캐릭터 스탯은 보류. 무기 각성별 최대 체력/공격력은 스크린샷에서 입력.

## 주의 사항
- 헬파이어 아르쿠스는 공유 무기. `타오르는 화염 낙인`은 아리아나 위버 전용 50%, `발화하는 화염 낙인`은 Jr. 전용 30%, 일반 효과는 25%.
- 현 스키마는 전용효과별 착용자 FK가 없으므로 각 단계 본문에 적용 캐릭터를 명시했다. 두 전용효과가 동시 적용되는 의미가 아니다. 추후 Jr. 등록 시 착용자 구조 정규화를 검토할 수 있다.
- 화염 낙인 1~6의 피해 증가량은 7~12%. 지속시간은 전용 2턴/일반 1턴으로 달라 효과 공통 duration을 지정하지 않고 각 발동 스킬에 명시했다.
- 화염 지대는 3턴 유지되는 지대. 디버프 자체 지속시간이 3턴으로 표시된 자료는 아니므로 공통 duration은 미지정.
- 스나이퍼의 `고립된 상태`는 조건만 있고 별도 설명이 없어 가상의 디버프를 만들지 않음.
- 무기 이미지의 Lv/별/자물쇠는 AI 보정으로 제거. 가려진 활 끝/활시위는 추정 복원이다.
