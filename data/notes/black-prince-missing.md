## 사용자 확인 완료 — 2026-10-29

- **궁극 그리마**: 아우터원 스킬은 발현 1단부터 존재함. 노발현 단계가 없는 것이 정상이며 자료 누락이 아님. 1·3·5단 유지, 화면의 자료 확인 중 안내 제거.
- **용아 : 여명**: 4성만 존재함. 1·2·3성 자료는 필요하지 않음. 4성(발현 6단)만 유지.
- **아토믹 블래스트**: 물리·마법 복합 공격 타입으로 사용자 확인. 별도 attackType을 `물리/마법`으로 지정해 클래스 기본 참격 표시를 대체. 설명의 물리 고정 피해와 인접 대상 추가 피해 문구는 원문 그대로 유지.

## 추정값과 입력 기준

- 일반 필살기 **아수라파천무 기본 185%**: 사용자 지침에 따라 190 → 195 → 200%의 단계 격차 5%p를 역산. 화면에도 추정 안내 표시.
- 출시일은 이전 캐릭터의 2주 간격을 적용하지 않고 사용자 지정 **2025-01-14**. 출현작 **창세기전2**, 분류 **아우터원**은 프로필 화면과 일치.
- 극한의 무 1~4의 지속 시간은 각성 설명에 표시가 없어 생략. 5~7·영자 축적·한계확장·이중 방어·전의 상실은 영구 표시 확인.
- 장착 상태 캐릭터 능력치는 등록하지 않음. 무기 기본 능력치는 각성 화면 기준.

## 다음 배포 시 주의

- **이번 요청은 커밋까지만**: 원격 푸시·배포는 하지 않음.
- API `018_character_outer_skill.sql` 마이그레이션 → API 재배포 → 데이터 동기화 → 프론트 배포 순서 필요.
- 아우터원 스킬은 JSON 원본으로 관리. 현재 관리자 폼에서는 별도 편집하지 않으며 기존 캐릭터 저장 시 그대로 유지됨.
- 로컬 DB 통합 검증/실서버 적용은 하지 않음. SQL 생성·회귀 검사·컴파일·로컬 화면 확인으로 검증.
