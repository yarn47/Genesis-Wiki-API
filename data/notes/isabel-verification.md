# 이자벨 리피네 등록 확인

## 입력 근거

- 이자벨.zip, Screenshot_20261110_111646~112021 총 37장.
- 출시일: 사용자 지시 '2주뒤' → 에스테 도데(2025-03-18)에서 2주 뒤인 2025-04-01.
- 출현작: 서풍의 광시곡. 소속 지역: 게이시르 / 제피르팰컨.
- 프로필의 분류 '이너브레이크'는 소속 지역과 별개의 항목이다. 현재 분류 필드가 없어 소속을 덮어쓰지 않고 이 기록에 보존한다.
- 각성 4성은 사진에 없었으나 사용자 답변 '방저 25 호위시 15 감소'로 보완: 방어력/저항력 +25%, 인접 아군 호위, 호위 시 받는 피해 15% 감소. 반격 사거리 증가는 5성부터.
- 발현 6단에서 호위 범위가 인접 → 주위 2칸. 강철 관통 최대 중첩은 2/4/6, 지속 2턴.
- 천공일섬 발현 1/3/5단: 공격력과 방어력 계수 각각 80/90/100%. 노발현은 사용자 공통 지시에 따라 각각 70%로 역산. 노발현 실물 화면을 확인한 값은 아니다. 기절 1턴 유지.
- 클래스: 솔져→가드→워로드/랜스워든, 솔져→가디언→아이언가디언. 기존 솔져·가드·가디언 데이터 재사용.
- 아티팩트 순서: 최상의 상태 / 응징의 서약 / 방패의 공명 / 재기의 바람. 기존 3종 재사용. 방패의 공명 단계 3~6은 한 명당 3/4/5/6%, 최대 12/16/20/24%.
- 지면 분쇄의 느려짐 1은 2턴이므로 기존 1턴 효과와 구분한 이름으로 등록했다.
- 전투 지휘의 선택지 3개와 고무의 쿨타임 감소를 본문에 함께 보존했다.
- 전용무기 신의 심판은 전투 **전**, 일반 신성한 심판은 전투 **후** 발동. 전용 5/6성에서 버프 1/2개 해제, 일반은 6성만 1개 해제.
- 캐릭터 현재 스탯은 장착 상태의 영향을 받아 입력하지 않았다.

## 추가 확인 사항

- 지면 분쇄·철벽진입의 물리 고정 피해 문구는 입력했다. 별 모양 공격 타입 문양의 공식 명칭은 명확히 식별되지 않아 별도 attackType은 지정하지 않았다. 현재 화면은 클래스 기본 관통을 보조 표시한다. 피해 계산 방식과 공격 타입은 구별해야 한다.
- 나머지 제공 자료와 사용자 각성 4성 보완 내용은 입력 완료.
