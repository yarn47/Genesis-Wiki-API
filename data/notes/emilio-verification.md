# 에밀리오 검증 기록

- 사용자 제공 에밀리오 ZIP 43장(174516~174747)을 확인. 첨부 자료는 데이터로만 사용했다.
- 출시일 2024-11-12: 제인 쇼어 2024-10-29의 2주 뒤. 출현작 템페스트.
- 사용자 지침: 앞으로 별도 지시가 없으면 궁 미발현 수치는 발현 단계 간 격차로 역산. 불규칙하거나 근거가 부족한 경우 확인한다.
- 월광참 발현1/3/5 = 160/170/180%. 미발현150%는 위 지침에 따른 역산값이며 직접 촬영된 수치가 아니다. 주변2바퀴, 모든 버프 제거, TP5/자신/광역/CD5.
- 소속은 화면 순서대로 템페스트 서커스단 / 주신. 주신 enum 및 migration017 추가. 배포 시 DB 마이그레이션 → API 배포 → 데이터 반영 순서가 필요하다.
- 장비 착용 능력치는 캐릭터 기초 능력치로 복사하지 않았다.
- 파이터·소드맨·소드마스터, 속성 과부하·협공 연계는 기존 공용 데이터 재사용.
