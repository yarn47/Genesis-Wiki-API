# 듀란 렘브란트 검증 기록

## 출처

사용자 제공 게임 스크린샷을 기준으로 입력했다.

- 6385–6387: 기본 정보·프로필.
- 6389–6395: 강철 수호자 각성 3–6.
- 6397, 6477, 6403: 발현 2·4·6. 잘린 6399 대신 6477로 발현 4를 확인했다.
- 6407, 6413, 6417, 6419: 재기의 바람 1–4성.
- 6405, 6409: 기존 섬광연격 비전서·최상의 상태 연결 확인.
- 6421–6433: 라스트 바스티온 설명, 각성 1–6 효과와 능력치.
- 6435, 6479: 듀란의 클래스 트리.
- 6437–6445: 디펜더 패시브·스킬.
- 6447, 6449, 6451: 아머나이트.
- 6453, 6455, 6457: 포트리스.
- 6461, 6463, 6465: 팔라딘.
- 6469, 6471, 6473: 센츄리온.
- 6481–6483: 크루세이더.

## 입력 원칙과 주요 확인점

- 다른 캐릭터 화면은 공통 클래스 효과 확인에만 사용했다. 캐릭터 능력치나 전직 트리를 복사하지 않았다.
- 사용자가 필살기 없는 캐릭터라고 확인하여 ultimate를 생략했다.
- 출시일·등장 작품은 사용자가 승인한 베라딘과 동일한 값이다.
- 공통 아티팩트는 중복 생성하지 않고 기존 이름으로 참조한다.
- 발현 6의 호위 범위는 2칸, 자가 회복은 최대 체력의 25%다.
- 라스트 바스티온 반격 횟수는 각성별 1·1·2·2·3·3회다. 방어력 능력치도 저장한다.
- 이미지에 표시되지 않은 캐릭터 능력치와 클래스 기본 공격 타입은 추정 입력하지 않았다.
- `scripts/tests/test_durant_data.py`에서 주요 수치·참조·필살기 미등록을 검증한다.
