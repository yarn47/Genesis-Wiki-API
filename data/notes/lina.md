# 리나 맥로레인 자료 근거

- 출시일: 2024-06-04. 사용자가 2024-06-11에서 정정.
- 출현작: 템페스트 (사용자 지정).
- 프로필: 10467·10469. 추가 소속 `템페스트 서커스단`, 분류 `이너브레이크`는 현재 캐릭터 모델에서 지원하지 않아 여기 보존한다.
- 고유 패시브 각성 3~6: 10471~10485. 발현 2/4/6: 10491·10493·10495.
- 디바인 에오스 발현 1/3/5: 10511·10513·10515. TP·사거리·쿨타임은 10489.
- **노발현은 화면 확인값이 아닌 사용자 승인 역산값**: 기본 회복 100%, HP 50% 이하 추가 회복 50%, 축복의 진언 능력치 ±7.5%. 발현 단계 간 차이 5%p/5%p/2.5%p를 차감했다. 노발현 버프 이름은 화면 미확인으로 `축복의 진언 (기본)`으로 구분했다.
- 신성의 인도자: 10517~10529. 버프 이름 `신성한 목도`는 화면 표기 그대로다. 각성 5단부터 공격력/주문력 +10% 추가. 일반 인도 효과와 전용 효과는 별개로 보존.
- 무기 최대 체력: 130/131/132/134/135/136. 사용자 설명대로 3→4단만 +2, 나머지 +1.
- 무기 주문력: 사용자 지정 342부터 단계당 +4 → 342/346/350/354/358/362. 화면에서 직접 확인한 수치와 구분.
- 클래스 트리 10531: 시스터→프리스트·클레릭, 프리스트→리터너, 클레릭→메이터·오라클. 시스터·프리스트·클레릭·메이터는 기존 공용 데이터 재사용.
- 리터너 기도 1/2와 리콜: 10533·10535·10537. 썬 라이트는 툴팁의 해제 불가 표기를 보존.
- 오라클 예지 1/2와 트랜스: 10539·10541·10543. 예지 UI 사거리는 2지만 현재 클래스 패시브 모델은 사거리 필드가 없다. 본문에 임의로 2칸 범위 조건을 추가하지 않았다. 트랜스의 회복 발동 시점은 화면의 `아군이 캐릭터 턴 종료 시`를 그대로 보존.
- 계시의 봉화: 10497·10503·10507·10509, 마법 피해 감소 8/12/16/20%. 집중은 기존 버프 재사용.
- 원소통달: 광휘·순례자의 덧신: 10499·10501과 기존 아이린 공용 데이터 일치, 기존 모든 단계 재사용.
- 장비가 적용된 캐릭터 능력치는 등록하지 않음.
- 원본 사진은 프런트 저장소의 Git 제외 경로 `.local-reference/lina/`에 보존. 무기 카드 UI 보정으로 가려진 끝부분 복원은 추정.
