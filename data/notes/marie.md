# 메리 팬드래건

- 사용자 제공 스크린샷 고유 47장(11305~11399 중 11385 제외)을 기준으로 입력.
- 출시일: 에스메랄다 2024-08-20의 2주 뒤인 2024-09-03. 출현작 템페스트. 사용자 지정.
- 레인저·스카우트·하이마스터, 약화·둔화, 필살 대응 수호·생명의 맥동은 기존 공용 데이터 재사용. 공유 클래스의 무기 정의는 변경하지 않음.
- 도미넌트→파이썬/쏜즈퀸 신규 등록. 에로틱 스카의 화면 사거리 2는 기존 단일 숫자 규칙에 따라 [2,2]. 허용 무기 문구는 없으므로 임의 추가하지 않음.
- 발현 4단 협공/회복 45%는 11321 이전 단계에서 확인. 발현 6단 협공/회복 50%는 11399에서 확인.
- 무기 6성 추가 공격력 15%는 11397에서 확인. 4성부터 황홀한 유린에 약화 2턴 추가. 피해/쿨타임/보호막 및 하단 능력치 모두 확보.
- 질투의 가시는 지속 턴이 표시되지 않아 duration 생략. 최대 3중첩, 1~2성 쿨타임3 / 3~4성 쿨타임2.
- 견편인무·탄편인무·황홀한 유린은 게임의 상세 효과 팝업을 버프 사전으로 연결. 임의 지속 턴을 추가하지 않음.
- 장착 상태 캐릭터 능력치와 무기 무작위 특화는 입력하지 않음.

## 배포 순서

템페스트 서커스단(tempest_circus) 진영 추가로 데이터만 배포하면 안 됨.
1. 016_tempest_circus_faction.sql 마이그레이션 적용 (기존 enum 값은 모두 보존).
2. 서버 재배포 (새 Faction enum 포함).
3. 데이터 동기화 및 프론트 배포.

이번 작업에서는 로컬 수정/검증만 수행. 서버에 마이그레이션이나 데이터를 적용하지 않음.

## 검증

- Python 데이터 테스트 152개 통과, SQL 생성 경고 없음.
- Kotlin 캐릭터 요청 테스트 통과, 서버 코드 컴파일 성공.
- 전체 서버 테스트는 로컬 DB 연결이 없어 contextLoads 실패. 실제 DB 마이그레이션은 미검증.
- JSON을 API 응답 형식으로 변환하는 로컬 미리보기에서 목록/상세, 파이썬 선택, 패시브 발현6단 선택, 질투의 가시 및 전용무기 펼침 확인. 실제 서버/DB 통합 검증과 구분.
