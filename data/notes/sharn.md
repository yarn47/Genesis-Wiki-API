# 샤른호스트 자료 기록

- 사용자 제공 게임 스크린샷 10639~10721, 41장 기준. 10701은 10699와 동일한 3단 하단 화면.
- 출시일: 2024-06-25. 사용자 정정 기준 리나 2024-05-28 → 코델리아 2024-06-11 → 샤른호스트 2024-06-25(각 2주 간격).
- 출현작: 템페스트. 프로필 영어 표기는 Sharn Hoiste.
- 10641의 소속은 템페스트 서커스단, 분류는 이너브레이크. 현재 진영 분류는 같은 서커스단인 자드와 동일하게 무소속으로 연결한다. 게임 원문 소속을 새 진영으로 임의 추가하지 않았다.
- 장비가 적용된 캐릭터 스탯은 등록하지 않았다.

## 보존한 차이

- 왕자의 이중 생활: 체력 기준 45/55/60/70/75/80/85%, 치명타 확률 10/15/25/30/30/40/50%. 버프 3부터 TP 제거 면역, 6부터 치유 불가 부여, 7에서 TP 흡수 2.
- 다크프린스의 어둠 장막은 사진상 영구·최대 3중첩. 기존 공용 어둠 장막(5중첩)을 변경하지 않고 '어둠 장막 (다크프린스)'로 구분했다. 괄호는 위키 식별용이며 게임 이름은 어둠 장막이다.
- 인지니어스는 표시된 쿨타임 1턴을 저장하되 사용한 스킬의 쿨타임 적용 설명도 유지한다. TP '-'는 생략한다.
- 아수라파천무의 주변 '3바퀴', 타격, 원거리/추방상태공격 태그를 보존한다. 치명타 피해 증가의 지속시간은 사진에 없어 추정하지 않는다.
- 스톰블링거 보호막: 30/35/45/50/55/60%. 3단은 40%가 아니라 45%. 지속 2턴, 쿨타임 4/4/4/4/3/3턴.
- 뇌신의 부름: 25/30/35/40/45/50% 전격. 썬더 스톰: 15/20/25/30/35/40% 전격. 각각 감전 1턴 부여. 기존 감전 공용 항목 자체의 지속시간은 변경하지 않는다.
- 사진의 뇌신의 부름/썬더 스톰 해제 불가는 각각의 효과 항목에 기록한다.

## 검증

샤른 전용 회귀 테스트 6개, 전체 API 123개 및 프론트 5개 통과. SQL 생성 경고 없음. 프론트 빌드 통과. 로컬 상세 화면에서 신규 클래스 3종, 패시브 발현 6단, 아티팩트 및 전용무기 각 단계 표시와 이미지 로딩을 확인했다. 커밋/배포는 별도 승인 사항이다.
