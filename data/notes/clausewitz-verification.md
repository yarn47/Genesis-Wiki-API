# 클라우제비츠 검증 기록

- 자료: 사용자 제공 클라우제비츠.zip 34장, 클라우제비츠2.zip 11장 (2026-10-27).
- 출시일: 사용자가 지정한 이전 캐릭터 출시 2주 뒤, 메리 팬드래건 2024-09-03 기준 2024-09-17. 출현작: 서풍의 광시곡.
- 프로필, 고유 패시브 각성 3~6/발현 2·4·6, 필살기 발현 1·3·5, 무기 각성 1~6을 사진에서 확인.
- 필살기 미발현 110%는 사용자 승인에 따라 발현 1의 120%에서 관측된 단계 간 차이 10%p를 차감한 추정값. 추가 낙뢰 50%는 변경하지 않음.
- 클래스 트리: 메이지 → 매지션 → 아크메이지/윈드윌더, 메이지 → 택티션 → 스키머. 기존 공용 클래스 3개는 재사용.
- 아티팩트 세 종류는 기존 항목과 ★1 효과가 일치하므로 기존 전체 단계/아이콘 재사용.
- 신비 병사의 위치 사수는 기존 솔저 계열 위치 사수와 범위·감소 수치가 다름. `위치 사수 (신비 병사)`로 분리해 기존 항목을 변경하지 않음.
- 발현 6의 면역 지속 시간은 사진에 없으므로 영구 등 임의 추정하지 않음. 발현 2·4는 각각 2·3턴.
- 무기 최대 체력 증가율은 추가 능력치 문구에 기록. 기본 체력은 사진 수치를 그대로 사용하며 증가율을 재가산하지 않음.
- 캐릭터 화면의 장착 후 스탯은 기본 스탯으로 등록하지 않음.
- 커밋·푸시·배포는 별도 사용자 요청 전까지 수행하지 않음.
