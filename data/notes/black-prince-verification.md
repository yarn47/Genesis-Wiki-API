# 흑태자 등록 검증 — 2026-10-28

## 출처

사용자 제공 `흑태자.zip`의 JPG 46장. 촬영 시각 파일명 기준:

- 184548/184550: 정보·프로필·아우터원 분류
- 184601~184626: 고유 패시브 각성 3~6단 및 버프 1~4
- 184634/184639/184644: 패시브 발현 2/4/6 및 버프 5~7, 이중 방어
- 184651~184723: 필살기와 궁극 그리마 발현 단계
- 184741~184801: 클래스 트리, 검황·데스로드 패시브 및 액티브
- 184825~184903: 아수라 각성 1~6단, 전용·일반 효과와 기본 능력치
- 184913~184928: 공용 아티팩트 세 종류와 용아 : 여명

## 검증 결과

- SQL 생성 성공, 신규 데이터의 색상·태그·클래스·무기·버프 참조 경고 없음.
- 데이터 회귀 검사 192개 통과(흑태자 7개 포함).
- 프론트 빌드와 기존 정렬·클래스 연결 검사 5개 통과.
- API 서비스·요청 DTO 단위검사 통과. 일반 필살기와 아우터원 스킬의 독립 ID/단계, 일반 캐릭터의 빈 outerSkill 검사 포함.
- 로컬 JSON 기반 미리보기에서 지정 날짜·출현작·아우터원 분류·초상화 표시 확인.
- 발현 5단 선택 시 아수라파천무 200%와 궁극 그리마 최대 체력 30%/고정 피해 60%를 별도 표시하는 것 확인.
- 기존 공용 아수라파천무 아이콘은 변경하지 않고 흑태자 전용 파일명으로 분리.
- 실제 DB 마이그레이션 및 서버 배포는 이번 요청 범위에 포함하지 않음.

부족 자료 및 추정값은 `black-prince-missing.md` 참조.
