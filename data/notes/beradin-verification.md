# 베라딘 스크린샷 대조 기록

사용자가 제공한 게임 화면만 사용. 출시일·출현작은 “이전과 같아” 지시에 따라 이전 이루스 데이터와 동일하게 입력.

- 6257~6259: 프로필·고유 패시브 아이콘.
- 6261~6305: 메이지 계열 6클래스, 클래스 패시브 각 2단계, 액티브 8개.
- 6307·6315·6317·6319: 헥스 엘리멘탈 블래스트 기본/발현 1/3/5, 150/155/160/165%.
- 6355·6357·6359·6361: 파멸의 고리 스킬 Lv 3~6 = 각성 3~6, 버프 번호는 1~4.
- 6309·6311·6313: 고유 패시브 발현 2/4/6, 버프 번호 5~7.
- 6331~6353: 전용무기 각성 1~6 전용/일반 효과, 최대 체력, 주문력, 마법 관통.
- 6363: 음모의 콘스텔라 이름·등급·플레이버 설명.
- 간이 보호 부적: 6321/6365/6373/6379, 보호막 40/60/80/100%.
- 치밀한 준비: 6323/6367/6375/6381, 공격력·주문력 15/20/25/30%, 시작 TP 1.
- 깜빡이는 보주: 6325/6371/6377/6383, 주문력 10/11/13/15%, 순간이동 확률 50/60/70/90%.
- 6369는 6367과 같은 2성 치밀한 준비. 6373 중복 첨부는 같은 자료.

## 데이터 표현상 주의

- 결정화는 게임 이름이 같지만 클래스 패시브 단계에 따라 회복량이 70/100%로 다름. 사용자에게 구분되도록 레벨 이름을 `결정화 (결정의 마력 1/2)`로 명시.
- 감전 지속은 스킬에 따라 1/2턴이므로 디버프 공통 지속값을 고정하지 않음.
- 다중 속성 스킬을 임의의 단일 속성으로 지정하지 않음. 트리플의 세 속성은 본문에 기록.
- 클래스 공격 타입은 화면에서 확인되지 않아 생략. 캐릭터 스탯·스킨·인연은 기존 등록 범위에서 제외.
- 무기 수치 키는 `spellAttack`, `magicPen`. 프론트 공용 WeaponInfo 표에 이 두 열 지원 추가.

검증: SQL 생성 경고 없음, 데이터 단위 테스트, 프론트 빌드, 로컬 JSON 읽기 전용 미리보기 확인. 운영 DB 반영은 별도 승인 후 진행.
