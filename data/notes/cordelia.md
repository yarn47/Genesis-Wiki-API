# 코델리아 오스틴 자료 대조 기록

## 출처와 반영 범위

- 사용자 제공 사진 10545~10637 중 46장. 10615는 미제공.
- 출시일: 리나 맥로레인(2024-06-04) 2주 뒤인 2024-06-18. 출현작: 템페스트 (사용자 지정).
- 프로필 10545/10547, 각성 패시브 10549~10563, 발현 패시브 10569~10573.
- 필살기 기본 10567, 발현 1/3/5단 10575/10577/10579.
- 아티팩트 10581~10591, 클래스 10593~10611, 전용무기 10613/10617~10637.
- 기존 아처·막스맨·스나이퍼, 속성 과부하·질풍의 깃, 감전·철수·엄폐는 공용 데이터를 재사용한다.
- 신규 클래스 3종, 아티팩트 1종, 버프 9종, 디버프 2종, 무기 1종 및 설치 태그.
- 장착 상태의 캐릭터 스탯은 등록하지 않았다.
- 프로필의 추가 소속 ‘템페스트 서커스단’과 분류 ‘이너브레이크’는 현 진영 열거형/스키마에 대응하지 않아 이 기록에 보존한다.

## 대조 시 주의 사항

- 퓨즈 폭탄은 전격 피해이며 감전을 부여한다. 110/115/125/130%, 사거리 4, 폭발 타일 주위 1칸.
- 테슈브의 낙진은 화염 피해 35/45/50/60% + 주변 65/65/70/70%. 사거리 3, 대상 주위 2칸.
- 발현 패시브는 폭탄 4레벨을 유지하며 공격력/피해 감소 10/20/30%와 아군 잔해 회수 시 추가 행동을 추가한다.
- 네이팜 블라썸은 기본부터 90/100/110/130%. 끈끈이 불꽃은 25% 화염 고정 피해, 2턴.
- 취급 주의! 스킬의 상자 유지시간은 2턴이지만 상자 툴팁에는 영구로 표기되어 있다. 각 원문을 각각 보존했다.
- 깜짝 깜찍 함정 범위는 ‘주변 1바퀴’를 유지했다. 남은 TP가 있으면 1TP를 써 한 번 더 사용하며 무제한 반복으로 바꾸지 않았다.
- 폭발적 발상은 착용자/설치물 피해 및 설치 스킬 시전에 발동한다. 화력 강화는 착용자 피해에만 발동한다.
- 폭발적 발상 1~6레벨: 각 +2%, 최대 5~10중첩, 1~4레벨 2턴/5~6레벨 3턴.
- 화력 강화 1~4레벨: 각 +2%, 최대 3~6중첩, 2턴. 무기 각성별 레벨은 1/2/2/3/3/4.
- 무기 기본 능력치는 Lv50 사진 기준이다. 체력 120/121/122/124/125/126, 공격력 370/373/377/381/384/388.

## 추가 확인 완료

- 타라니스 슈터 각성 1단 추가 능력치는 사진 상단이 잘렸으나, 사용자가 공격력 +10%임을 확인했다.
- 각성 1~6단 추가 공격력 +10/11/12/13/14/15%로 확정 반영했다. 2~6단은 사진으로 확인했다.

## 검증

- SQL 생성 검증: 경고 없이 통과.
- API 테스트 117개, 프론트 테스트 5개 및 프로덕션 빌드 통과.
- 로컬 상세 화면에서 프로필/출시일, 신규 클래스 3종 선택, 아티팩트 및 무기 전 단계와 이미지 로딩 확인.
- 서버 DB, 커밋, 푸시, 배포는 수행하지 않았다.
