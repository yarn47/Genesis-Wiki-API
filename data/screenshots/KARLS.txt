================================================

40장 / 1972x1248 / JPEG

이 문서는 "이 스크린샷에서 무엇을 읽어 어느 파일에 넣었는지"를 적어둔 것이다.
다음 캐릭터를 넣을 때 같은 순서로 하면 된다.

■ 폴더
  원본/        40장.  번호_캐릭터_화면.jpg
  index.tsv    번호·파일명·화면·내용 (엑셀로 열면 됨)
  README.txt   이 파일

  화면 약어:  profile=캐릭터 정보   passive=고유 패시브 팝업   class=클래스 탭
              manifest=발현 트리     weapon=장비 탭            weapon-awaken=장비 강화>각성
              artifact=아티팩트      skill=스킬 탭             ref=참고(다른 캐릭터)


================================================
작성 순서 — 반드시 이 순서로
================================================
버프/디버프 → 클래스 → 전용무기 → 캐릭터
뒤 단계가 앞 단계를 "이름"으로 참조하기 때문에 순서를 지켜야 한다.
전부 쓴 뒤  python3 scripts/gen_sql.py  로 검증하면
오타·없는 태그·끊어진 버프 이름을 반영 전에 잡아준다.


[1] 캐릭터 정보 화면          → 002번
------------------------------------------------
읽는 값:  이름 / 출생 연도 / 소속 진영 / 신장 / CV / 소개글
넣는 곳:  data/characters/karls.json
          name, birthYear, height, faction, cv, profileText

★ 화면에 없는 값 3개는 따로 확인해야 한다:
    grade(등급) · element(속성) · releaseDate(출시일) · appearedIn(출현작)
  등급과 속성은 캐릭터 획득 화면이나 도감에서 확인. 물어보는 게 빠르다.

★ 이 스크린샷에서 초상화(450x600)와 썸네일(420x560)도 잘라낸다.
    sips -c 1000 750 --cropOffset 120 255 원본/002_karls_profile.jpg --out p.png
    sips -z 600 450 p.png        # 초상화
    sips -z 560 420 p.png        # 썸네일


[2] 클래스 트리 화면          → 015번
------------------------------------------------
읽는 값:  티어 구조와 상하 연결, 클래스 이름
넣는 곳:  data/classes/<계열>.json  의 name / tier / parent
          data/characters/karls.json 의 classTree (티어 순서대로 나열)

★ 클래스는 캐릭터 공용이다. 이미 등록된 클래스면 이 단계를 건너뛴다.
  칼스는 파이터·나이트·아크나이트가 이미 있었고
  글라디에이터·다크나이트·드래곤슬레이어 3개만 새로 만들었다.
★ 같은 계열이라도 캐릭터마다 타는 3티어가 다르다.
  (이올린은 소드맨/로얄나이트 쪽, 칼스는 글라디에이터 쪽)
★ 엠블럼 아이콘(146x146)을 여기서 자른다. 노드가 금색이라
  채도(R-B > 45)로 훑으면 좌표가 정확히 나온다.


[3] 클래스별 패시브·액티브 툴팁   → 004, 006, 007, 009, 012, 014 / 003, 008, 010번
------------------------------------------------
읽는 값:
  클래스 상세(우측)  사용무기 / 방어 타입 / 공격 사거리 / 이동 거리 / 설명
  클래스 패시브      Lv1·Lv2 두 개 다 필요
  액티브 스킬        TP / 사거리 / 범위 / 쿨타임 / 허용 무기 / 태그 / 효과문
넣는 곳:  data/classes/<계열>.json 의 passive.lv1, lv2, skills[]

★ 스킬 이름 옆 배지 두 종류를 꼭 본다:
    어두운 원형 문양 = 공격 타입 (참격/관통/타격/마법/절단)
    옆의 색 아이콘   = 속성 (빙한 파란✳ / 화염 빨간불꽃 / 전격 / 암흑 보라초승달)
  문양이 없으면 attackType을 생략한다 → 클래스 기본값을 물려받는다.
  칼스에서는 다크 임브레스가 마법·암흑이었다.

★ 툴팁 옆에 딸려 나오는 빨간/파란 박스가 버프·디버프다.
  → data/buffs|debuffs/<계열>.json 에 먼저 등록한다.
    이름 / 효과 / 지속 턴 / 최대 중첩 / 태그
    지속·중첩·해제불가는 본문에 쓰지 않고 duration·maxStack·tags로 넣는다.
  칼스에서 새로 나온 것: 버프 전의, 디버프 파열·약화
  태그도 없으면 data/tags.json에 추가 (지속 피해, 출혈을 새로 넣었다)

★ 클래스 패시브·스킬 아이콘(116x115)은 '획득 스킬' 줄에서 자른다.
  y=353, 3개일 때 x=1380/1504/1626, 5개일 때 x=1257/1380/1504/1627/1750 (가운데 정렬)


[4] 고유 패시브 팝업 Lv3~6       → 001, 005, 013, 016번
------------------------------------------------
읽는 값:  각성 4단계의 효과문
넣는 곳:  data/characters/karls.json 의 passive.levels
          type "각성", step 3·4·5·6

★ 팝업 본문이 길면 스크롤해서 끝까지 찍어야 한다.


[5] 발현 트리 — 고유 스킬 2·4·6단   → 011, 036, 037, 038번
------------------------------------------------
읽는 값:  같은 패시브의 발현 단계 효과문
넣는 곳:  같은 passive.levels, type "발현", step 2·4·6  (총 7단계가 된다)

★ 트리에서 노드를 눌러야 우측에 "현재 단계"가 나온다.
  2단은 이전 단계가 없어 "현재 단계"만, 4·6단은 "이전 단계"도 같이 나온다.
★ 고유 패시브 아이콘(136x136)은 이 화면 우측 패널에서 자를 수 있다.
  스킬 탭에서 자르면 툴팁에 가려질 수 있다.


[6] 발현 트리 — 초필살기 1·3·5단   → 033, 034, 035번
------------------------------------------------
읽는 값:  단계별 효과문
넣는 곳:  data/characters/karls.json 의 ultimate.levels, step 1·3·5

★ 0단(노발현)은 트리에 노드가 없다. 따로 확인해야 한다. 칼스는 70%였다.
★ TP·사거리·범위·쿨타임·태그·공격타입·속성은 여기 안 나온다.
  스킬 탭(023번)에서 읽어서 ultimate에 넣는다.
  (필살기도 클래스 스킬처럼 tags·attackType·element·area를 가진다)


[7] 장비 탭 — 무기 상세          → 039번
------------------------------------------------
읽는 값:  무기 이름 / 등급 / 종류 / 설명문 / 특화 옵션
넣는 곳:  data/weapons/karls.json 의 name, grade, weaponType, description

★ 각성 화면에는 무기 이름이 안 나온다. 이 화면이 꼭 필요하다.
★ 무기 카드 그림도 여기서 자른다 (금색 카드 영역 전체).


[8] 장비 강화 > 각성 ★1~★6      → 017, 019, 020, 021, 022, 025, 026, 027, 028, 030, 031, 032번
------------------------------------------------
한 단계당 상단·하단 두 장이 필요하다. 스크롤해서 둘 다 찍는다.
  상단:  추가 능력치(공격력 +N%) + 전용효과
  하단:  일반효과 + 최대 체력 / 공격력 수치
넣는 곳:  data/weapons/karls.json 의 baseStats[] 와 effects[]
          type "전용" = 캐릭터 전용, "일반" = 공용 옵션

★ 전용/일반 구분이 중요하다. 일반효과에서 나오는 버프는
  캐릭터가 아니라 "무기 소속"으로 위키에 표시된다.
★ 무기 효과가 시전하는 효과([파열진 6] 같은 것)도
  data/buffs/*.json 에 레벨 1~6짜리 버프로 따로 등록해야
  효과문의 이름에 툴팁이 연결된다.


[9] 발현 트리 > 아티팩트         → 018, 024, 029번
------------------------------------------------
읽는 값:  이름 / 등급 / 플레이버 텍스트 / ★1~★4 효과
넣는 곳:  data/artifacts/karls.json
          ★1~★4 = levels 의 step 3·4·5·6  (발현 3~6단에 대응)

★ 아티팩트도 캐릭터 공용이다. 이미 있는 것이면 다시 넣지 않고
  캐릭터의 artifacts 배열에 이름만 적는다.
★ 아이콘(156x156)은 팝업 우상단에서 자른다.


================================================
마무리
================================================
1. python3 scripts/gen_sql.py       검증 (경고 없으면 통과)
2. 아이콘은 프론트 저장소 public/icons/ 에 커밋
3. 서버에서  git pull && ./scripts/db-sync.sh
   DB 구조가 바뀐 커밋이면  db-migrate.sh → deploy.sh → db-sync.sh 순서

아이콘 두는 곳 (프론트 public/icons/):
  classes/emblem/    클래스 엠블럼      classes/passive/  클래스 패시브
  skills/            클래스 액티브      passives/         캐릭터 고유 패시브
  ultimates/         초필살기           artifacts/        아티팩트
  weapons/           전용무기           characters/       <영문>_thumb / _portrait
